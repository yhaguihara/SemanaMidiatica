# 🎨 Semana Midiática — Sustentabilidade, Criatividade e Inteligência Artificial

Projeto web desenvolvido para a Semana Midiática, explorando como a inteligência artificial está transformando áreas criativas e o mercado de trabalho.

## 📖 Sobre o projeto

O site apresenta a pergunta **“Ainda existe espaço para a criatividade humana?”** e convida o visitante a refletir sobre o impacto da IA em diferentes áreas. A página inicial reúne cartões que levam a conteúdos sobre artes visuais, design, audiovisual, economia e mercado de trabalho.

O projeto foi desenvolvido como atividade de Programação Web I na ETEC Cidade Tiradentes.

## ✨ Funcionalidades

- 🧠 Apresentação do tema da criatividade humana diante da inteligência artificial.
- 🎨 Páginas sobre artes visuais e design.
- 🎬 Conteúdo sobre audiovisual.
- 💼 Reflexões sobre economia e mercado de trabalho.
- 🃏 Cartões de navegação para acessar os temas.
- 🎨 Layout personalizado com CSS e fontes externas.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura das páginas e conteúdo.
- **CSS3:** estilos, organização visual e layout.
- **JavaScript:** comportamento interativo da página.
- **Google Fonts:** tipografia personalizada.

## 🚀 Como executar o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/yhaguihara/SemanaMidiatica.git
   ```
2. Entre na pasta:
   ```bash
   cd SemanaMidiatica
   ```
3. Abra o arquivo `index.html` no navegador.

## 🎯 Objetivo de aprendizagem

Praticar a construção de páginas web interligadas, a organização de conteúdo, a estilização com CSS e o uso de JavaScript, além de refletir sobre a relação entre tecnologia, criatividade e sustentabilidade do trabalho.
